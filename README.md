# Microfrontend Learning Repository

This repository contains practical implementations of Microfrontend (MFA) architectures.

## 📁 Folders

* [Runtime-Microfrontend](./Runtime-Microfrontend) — Production-ready Runtime Microfrontend architecture using Vite 8, React 19, and `@originjs/vite-plugin-federation` featuring `shell`, `header`, `products`, and `cart`.

See [Runtime-Microfrontend/README.md](./Runtime-Microfrontend/README.md) for full architecture diagrams, port tables, event bus communication, and troubleshooting guides.
